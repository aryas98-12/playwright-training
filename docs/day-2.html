Playwright Training
DAY 2

Real UI Automation & Debugging

Hands-on learning and practice for your Playwright automation journey.

Learning Objectives

  • Handle common web controls.
  • Work with dialogs, tabs and frames.
  • Upload files.
  • Debug failed tests.

UI Controls

await page.getByLabel('Country').selectOption('India');

await page.getByRole('checkbox', {
    name: 'Accept Terms'
}).check();

await page.getByRole('radio', {
    name: 'Male'
}).check();

Dialogs

page.on('dialog', async dialog => {
    await dialog.accept();
});

New Tab

const pagePromise = context.waitForEvent('page');
await page.getByText('Open Report').click();
const newPage = await pagePromise;

iframe

const frame = page.frameLocator('#payment-frame');
await frame.getByLabel('Card Number').fill('1234');

Debugging

npx playwright test --debug
npx playwright test --headed
await page.pause();

Practice with Playwright Inspector, Trace Viewer, screenshots, videos, reports and browser DevTools.

Assignment

Automate a form containing text fields, dropdown, checkbox, radio button, file upload, iframe, dialog/popup, submit and success validation.
