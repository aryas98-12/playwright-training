DAY 3

Framework Design & Page Object Model

Hands-on learning and practice for your Playwright automation journey.

Learning Objective

Move from “I can write a test” to “I can build maintainable automation.”

Recommended Structure

tests/
pages/
fixtures/
utils/
test-data/
playwright.config.ts

Page Object Model

export class LoginPage {
    constructor(private page: Page) {}

    username = this.page.getByLabel('Username');
    password = this.page.getByLabel('Password');
    loginButton = this.page.getByRole('button', {
        name: 'Login'
    });

    async login(username: string, password: string) {
        await this.username.fill(username);
        await this.password.fill(password);
        await this.loginButton.click();
    }
}

Meaningful Page Methods

login()
logout()
searchUser()
createUser()
deleteUser()
Key idea: a Page Object should represent page/component behavior, not merely be a file containing locators.

Fixtures

Understand the built-in page, browser, context and request fixtures, then learn why custom fixtures are useful.

Configuration

Become comfortable with baseURL, screenshots, video, trace, retries, workers, projects, reporters and timeouts.

Assignment

Create LoginPage, DashboardPage and UsersPage with corresponding tests. Avoid duplicated code, use meaningful assertions and keep tests readable.
