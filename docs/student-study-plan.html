STUDENT GUIDE

5-Day Student Study Plan

Your goal is to become productive with Playwright in one week by combining focused learning with daily hands-on automation.

Your Goal

By the end of the week, you should be able to take a manual test case and independently convert it into a reliable Playwright automation test.

Think like an automation engineer: understand the requirement, choose reliable locators, design maintainable code, validate behavior, debug failures and improve reliability.

Day 1 — Playwright Fundamentals

  • Playwright Test Runner
  • Browser, Context and Page
  • Locators
  • Actions and assertions
  • Auto-waiting
  • Project structure

Commands

npm init playwright@latest
npx playwright test
npx playwright test --headed
npx playwright show-report

Locator priority

page.getByLabel()

page.getByText()
page.getByTestId()
page.locator()

Assignment

Automate: open application → login → verify dashboard → navigate to profile → update profile → verify success → logout.

Day 2 — Real UI Automation

  • Dropdowns
  • Checkboxes and radio buttons
  • Dialogs
  • Multiple tabs
  • Frames
  • File uploads
  • Keyboard and mouse actions
  • Debugging

Assignment

Automate a form containing text fields, dropdown, checkbox, radio button, file upload, iframe, dialog/popup, submit and success validation.

Day 3 — Framework & Page Object Model

  • Page Object Model
  • Reusable methods
  • Fixtures
  • Configuration
  • Test organization
tests/

fixtures/

playwright.config.ts

Assignment

Create LoginPage, DashboardPage and UsersPage, with corresponding test files. Avoid duplicated code and use meaningful assertions.

Day 4 — API, Authentication & Debugging

  • request.get/post/put/delete
  • API + UI testing
  • Authentication state and storageState
  • Network interception
  • Playwright Inspector and Trace Viewer

Debugging challenge

Fix a framework containing incorrect locators, missing awaits, bad assertions, hard waits, authentication problems, popup problems and flaky tests. Explain the root cause of each failure.

Daily Self-Check

Day 1

  • □ I can create a Playwright project.
  • □ I understand Browser, Context and Page.
  • □ I can choose appropriate locators.
  • □ I can perform common actions.
  • □ I can write assertions.
  • □ I understand auto-waiting.

Day 2

  • □ I can automate forms.
  • □ I can handle dropdowns, checkboxes and radio buttons.
  • □ I can handle dialogs, tabs and iframes.
  • □ I can debug a failing test.

Day 3

  • □ I understand Page Object Model.
  • □ I can create Page Objects.
  • □ I understand fixtures and configuration.
  • □ I can organize tests properly.

Day 4

  • □ I can send API requests.
  • □ I understand API + UI testing.
  • □ I understand authentication state and storageState.
  • □ I understand network interception.
  • □ I can investigate flaky tests.

Day 5

  • □ I can build a small framework independently.
  • □ I can write maintainable tests.
  • □ I can run tests from the command line.
  • □ I can investigate reports.
  • □ I understand retries and parallel execution.
  • □ I understand the basic CI/CD workflow.
