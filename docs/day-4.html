DAY 4

API, Authentication & Debugging

Hands-on learning and practice for your Playwright automation journey.

Learning Objectives

  • Use Playwright for API calls.
  • Combine API setup with UI validation.
  • Understand authentication state.
  • Use network interception.
  • Diagnose failures systematically.

API Testing

const response = await request.get('/users');
expect(response.status()).toBe(200);
const response = await request.post('/users', {
    data: {
        name: 'John',
        email: 'john@test.com'
    }
});

expect(response.status()).toBe(201);
