DAY 1

Playwright Fundamentals

Hands-on learning and practice for your Playwright automation journey.

Learning Objectives

  • Understand Playwright and its architecture.
  • Create and run a Playwright project.
  • Choose reliable locators.
  • Perform actions and write assertions.
  • Understand auto-waiting.

1. Playwright Architecture

2. Project Setup

npm init playwright@latest
npx playwright test
npx playwright test --headed
npx playwright show-report

3. Basic Test

import { test, expect } from '@playwright/test';

test('verify page title', async ({ page }) => {
    await page.goto('https://example.com');
    await expect(page).toHaveTitle(/Example/);
});

4. Locators

Practice these first:

page.getByRole()
page.getByLabel()
page.getByPlaceholder()
page.getByText()
page.getByTestId()
page.locator()

5. Actions & Assertions

await page.getByLabel('Email').fill('test@gmail.com');
await page.getByRole('button', { name: 'Submit' }).click();

await expect(page.getByText('Success')).toBeVisible();
await expect(page).toHaveURL(/dashboard/);
Remember: avoid fixed waits such as page.waitForTimeout(5000) when Playwright can wait for the expected condition.
