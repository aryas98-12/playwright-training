Final Challenge

Given a requirement such as “Automate user registration and login. The framework must support multiple environments and users. Tests should run independently and generate a report,” decide the locator strategy, Page Objects, fixtures, test data, authentication approach, assertions, configuration, execution and debugging strategy.

Success Criteria

You do not need to memorize every Playwright API. You should be able to receive a requirement and independently design, implement, run, debug and refactor the automation.
